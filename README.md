# Friction Log

A tiny, local-first field research tool for designers. Capture what happened, the workaround or pain, how often it occurs, and its impact. Notes are ranked by a simple frequency × impact signal, turned into a follow-up research prompt, and exportable as Markdown.

## Run it

Open `index.html` in a browser. No build step, dependencies, account, or backend required. Notes are saved in that browser's local storage.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html` and `README.md`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will show the live site URL in the Pages section.

## A note on the signal score

Frequency × impact (1–9) is a lightweight sorting prompt, not a validated research metric. Use it to decide what to investigate next, not as proof of product-market demand.
